Authentication System - Guvi Internship Project

A secure user registration and login system with profile management using MySQL, MongoDB, and Redis.

Features
  • Secure Registration: Create a new account with email and password.
  • User Login: Authenticate with your credentials using Redis-based sessions.
  • Profile Management: Store and update your profile details (Age, DOB, Contact).
  • Hybrid Database: MySQL for authentication, MongoDB for profile data.
  • Security: Prepared statements, hashed passwords, and secure tokens.
